# WARP & WEFT — 리디자인 기획

wear-in 스크롤 경험(v2)을 롱폼 에디토리얼(v3)로 전면 개편하는 기획과 진행 상태.

## 콘셉트

데님은 인디고로 염색한 날실(warp)과 흰 씨실(weft)을 3x1로 짠다. 앞면은 파랗고 안쪽은 하얗다. 빈티지 감정 단서(셀비지, 숨은 리벳, 케어 라벨, 단추 뒷면 번호)도 대부분 안쪽에 있다.

| 레이어 | 메타포 | 역할 | 우선순위 |
| --- | --- | --- | --- |
| 롱폼 에디토리얼 | 앞면 (인디고) | 사이트의 몸통. 9개 챕터 + 각주 | P0 |
| Inside Out 감정 도구 | 안쪽 (흰 씨실) | 사이트를 "뒤집으면" 나오는 숨은 층 | P1 |
| Heritage Line 커머스 | 라벨 / 태그 | 챕터·감정 결과를 상품으로 잇는 부가 층 | P2 |

## 정보 구조

```
/                      표지 + 목차
/chapters/:slug        에디토리얼 9개 챕터
/sources               출처
/colophon              작업 소개, 비공식 고지
/inside-out            (P1) 감정 도구 — 링크는 숨기고 URL로는 접근 가능
/shop, /shop/:model    (P2) 헤리티지 라인 랜딩 + 상품 상세
```

## 진행 상태

### P0 — 완료 (editorial-redesign 브랜치)

- 라우팅(React Router, GitHub Pages `404.html` 폴백 유지), 마스트헤드, 목차 다이얼로그, 읽기 진행 바
- 각주 시스템: 본문 `[^sourceId]` 마커 → 번호 버튼 + 팝오버(모바일은 하단 시트), 챕터 끝 Notes, `/sources`
- 9개 챕터 원고 초안과 챕터별 시각화

| 챕터 | 시각화 | 방식 |
| --- | --- | --- |
| 01 Gold & Canvas | 이동 경로 도식 | 스크롤 스크럽 |
| 02 The Patent | 주머니 모서리 + 리벳 + 특허 스탬프 | 스크롤 스크럽 |
| 03 Lot 501 | 1890–1971 뒷면 변천 | 연도 슬라이더 + 이벤트 목록 |
| 04 War & Rebellion | 스티치 vs 페인트 아큐에이트 | 스크롤 스크럽 |
| 05 Indigo | 링 염색 단면 + 원단 견본 | 스크롤(염색 횟수) + 마모 슬라이더 |
| 06 The Loom | 3x1 능직 조직도 앞/뒷면, 직기 폭 비교 | 토글 |
| 07 The Spread | 지역별 확산 타임라인 | 스크롤 스크럽 |
| 08 Anatomy | 501 분해도 | 스티키 무대 + 스크럽 |
| 09 Worn | 물 사용량 3,781L 구성 | 스크롤 스크럽 |

- 3D(React Three Fiber, three.js) 제거, 기존 wear-in 컴포넌트 제거
- 디자인 토큰: 색 체계는 유지, 타이포를 에디토리얼로 교체 (Fraunces / Noto Serif KR / IBM Plex Sans KR / IBM Plex Mono)
- reduced-motion: 스크럽을 만들지 않고 최종 상태로 렌더

### 남은 P0 다듬기

- 원고 사실 대조: 각 각주를 원문(특히 Downey 2016, Sullivan 2006)과 대조. 이미 확인한 항목은 LCA 수치(68% 목화, 23% 소비자 세탁)와 501 디테일 연도(1937 숨은 리벳, 1941 가랑이 리벳, 1942 신치, 1955 종이 패치, 1971 스몰 e)
- 실제 특허 도면(US 139,121, 퍼블릭 도메인) 이미지를 2장에 추가 검토
- OG 이미지를 새 표지 기준으로 재생성
- 챕터 단위 코드 스플리팅 (현재 단일 번들 약 146 kB gzip)
- CASE_STUDY.md를 v3 기준으로 재작성

### P1 — Inside Out

- 진입: 챕터 곳곳의 "실밥" 단서 5개 수집 / 에필로그 마지막 문장 / 푸터·콜로폰의 작은 링크와 키보드 단축키(실제 버튼)
- 전환: 인디고 → 흰 씨실 색 반전, 사선 결 방향 반전
- 흐름: 질문 카드(레드탭 글자 → 뒷주머니 안쪽 리벳 → 패치 소재 → 셀비지 → 케어 라벨 → 단추 뒷면) → 답할 때마다 1873–현재 타임라인 위 가능 구간이 좁혀짐 → 추정 연대 + 근거 + 관련 챕터 링크 + 복각 모델 링크 + 공유 URL
- 모든 질문에 "모르겠음" 선택지, 결과에 "참고용" 고지

### P2 — Heritage Line

- 랜딩 1 + 상품 상세 템플릿 1, 시대별 복각 모델 3개 데이터
- 생지 데님 수축을 반영한 사이즈 추천기
- 결제 없음, 장바구니까지만 데모. `src/data/assets.ts`의 generated 제품 이미지 재사용 후보
