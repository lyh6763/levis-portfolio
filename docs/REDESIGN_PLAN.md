# WARP & WEFT — 리디자인 기획

wear-in 스크롤 경험(v2)을 롱폼 에디토리얼(v3)로 전면 개편하는 기획과 진행 상태.

## 콘셉트

데님은 인디고로 염색한 날실(warp)과 흰 씨실(weft)을 3x1로 짠다. 앞면은 파랗고 안쪽은 하얗다. 빈티지 감정 단서(셀비지, 숨은 리벳, 케어 라벨, 단추 뒷면 번호)도 대부분 안쪽에 있다.

| 레이어 | 메타포 | 역할 | 우선순위 |
| --- | --- | --- | --- |
| 롱폼 에디토리얼 | 앞면 (인디고) | 사이트의 몸통. 9개 챕터 + 각주 | P0 |
| Inside Out 감정 도구 | 안쪽 (흰 씨실) | 사이트를 "뒤집으면" 나오는 숨은 층 | P1 |
| Heritage Line 커머스 | 라벨 / 태그 | 챕터·감정 결과를 상품으로 잇는 부가 층 | P2 |

## 정보 구조

```
/                      표지 + 목차
/chapters/:slug        에디토리얼 9개 챕터
/sources               출처
/colophon              작업 소개, 비공식 고지
/inside-out            (P1) 감정 도구 — 링크는 숨기고 URL로는 접근 가능
/shop, /shop/:model    (P2) 헤리티지 라인 랜딩 + 상품 상세
```

## 진행 상태

### P0 — 완료 (editorial-redesign 브랜치)

- 라우팅(React Router), 마스트헤드, 목차 다이얼로그, 읽기 진행 바. 배포 후 딥 링크는 404.html 폴백 대신 라우트별 정적 HTML로 바꿈(아래 "배포")
- 각주 시스템: 본문 `[^sourceId]` 마커 → 번호 버튼 + 팝오버(모바일은 하단 시트), 챕터 끝 Notes, `/sources`
- 9개 챕터 원고 초안과 챕터별 시각화

| 챕터 | 시각화 | 방식 |
| --- | --- | --- |
| 01 Gold & Canvas | 이동 경로 도식 | 스크롤 스크럽 |
| 02 The Patent | 주머니 모서리 + 리벳 + 특허 스탬프 | 스크롤 스크럽 |
| 03 Lot 501 | 1890–1971 뒷면 변천 | 연도 슬라이더 + 이벤트 목록 |
| 04 War & Rebellion | 스티치 vs 페인트 아큐에이트 | 스크롤 스크럽 |
| 05 Indigo | 링 염색 단면 + 원단 견본 | 스크롤(염색 횟수) + 마모 슬라이더 |
| 06 The Loom | 3x1 능직 조직도 앞/뒷면, 직기 폭 비교 | 토글 |
| 07 The Spread | 지역별 확산 타임라인 | 스크롤 스크럽 |
| 08 Anatomy | 501 분해도 | 스티키 무대 + 스크럽 |
| 09 Worn | 물 사용량 3,781L 구성 | 스크롤 스크럽 |

- 3D(React Three Fiber, three.js) 제거, 기존 wear-in 컴포넌트 제거
- 디자인 토큰: 색 체계는 유지, 타이포를 에디토리얼로 교체 (Fraunces / Noto Serif KR / IBM Plex Sans KR / IBM Plex Mono)
- reduced-motion: 스크럽을 만들지 않고 최종 상태로 렌더

### P0 마무리 (완료)

- 사실 대조: 각주 서술을 온라인 공개 자료(주로 Levi Strauss & Co. 아카이브 글)와 대조하고 정정. 출처 25개 중 22개 대조 완료, 출처 페이지에 대조 여부 표시. 정정 내역은 CASE_STUDY.md "사실 검증" 참고
- 감정 단서·연도 슬라이더의 전시 규격 경계를 자료 편차(1941~1944)에 맞게 조정
- OG 이미지를 표지 기준 PNG(1200x630)로 재생성 (`npm run assets:og`)
- v2 이미지 파이프라인 제거(`src/data/assets.ts`, generated/placeholder 이미지, 관련 스크립트·npm 스크립트·`.env.*`), v2 문서는 `docs/legacy/`로 이동
- CASE_STUDY.md를 v3 기준으로 재작성

### 배포 (완료)

- GitHub Pages를 브랜치 루트 서빙(legacy)에서 GitHub Actions 배포로 전환. 이전에는 빌드 전 소스 index.html이 서빙되어 빈 화면이었다
- Vite `base`를 `/levis-portfolio/`로, canonical·OG를 `VITE_SITE_URL` 절대 주소로
- `scripts/prerenderRoutes.ts`: 라우트 16개의 `<path>/index.html`(라우트별 head), `404.html`(noindex), `sitemap.xml` 생성. 딥 링크가 404 대신 200으로 응답. 앱은 끝 `/`를 정리

### 코드 스플리팅 (완료)

- 첫 화면 JS gzip 약 160 kB → 약 91 kB (`vendor` 79 + `index` 12)
- 챕터 본문을 `src/content/chapters/<slug>.ts`로 분리하고 메타데이터만 첫 번들에 남김
- 표지 외 페이지와 시각화 9종을 지연 로딩. GSAP(45 kB)는 스크롤 스크럽 시각화와 함께 받음. Lenis는 자체 rAF(autoRaf)로 돌고 ScrollTrigger는 불러온 뒤에 연결
- `vendor` 청크 분리로 앱 코드가 바뀌어도 라이브러리 캐시 유지
- 라우트별 HTML에 modulepreload, 링크 포인터/포커스 시 미리 불러오기, 다음 챕터 유휴 시간 미리 불러오기
- 청크 로딩 실패 시 오류 경계로 안내, 지연 로딩 페이지의 해시 대상은 나타날 때까지 기다렸다가 이동
- 라우트 전환 직후 Lenis 내부 값이 이전 페이지 기준으로 남아 해시 이동이 목표를 지나치던 문제를 수정

### P1 — Inside Out (구현 완료)

- 진입 세 가지
  - 풀린 실밥 5개(01·03·04·06·08장 본문 여백). 실제 버튼이며, 수집 상태는 localStorage에 저장(실패해도 방문 중에는 유지). 5개째에 "뒤집어 보기" 알림
  - 09장 끝의 "이 사이트도 뒤집어 보기" 버튼
  - 모든 페이지 푸터의 Inside out / Face 버튼
  - 기획에 있던 단일 키 단축키(I)는 WCAG 2.1.4(문자 단축키) 문제로 넣지 않음
- 전환: 원단을 뒤집는 3D 시트(앞면 인디고·오른쪽 위 사선 ↔ 뒷면 흰 씨실·왼쪽 위 사선). reduced-motion이면 즉시 이동
- 안쪽 테마: `.site--inside`에서 지면·괘선 토큰을 흰 씨실 톤으로 바꾸고 반대 방향 사선을 깐다
- 감정 도구(`/inside-out`, 데이터는 `src/data/insideOut.ts`)
  - 단서 8개: 레드탭 글자, 뒷주머니 리벳, 가랑이 리벳, 신치, 패치 소재, 아큐에이트, 셀비지, 세탁 라벨. 모든 단서에 "모르겠음"
  - 답마다 구간을 교집합해 상단 고정 연표가 좁혀짐. 교집합이 비면 "복각·수선 가능성" 안내
  - 결과: 추정 구간, 구간을 정한 결정적 단서, 단서별 근거와 관련 챕터 링크, 답 바꾸기, 건너뛴 단서 확인, 결과 링크 복사(답을 쿼리스트링에 담음)
  - 단추 뒷면 공장 번호는 해석이 복잡해 이번 범위에서 제외
- 남은 일: 단서 구간 경계 연도의 원문 대조, 결과 → P2 복각 모델 링크

### P2 — Heritage Line (구현 완료)

- `/shop` 랜딩, `/shop/:slug` 상품 상세. 데이터는 `src/data/shop.ts` (가격·스펙·수축률은 가정값)
- 모델 3개: 1890 XX(03장), 1944 Wartime(04장), 1966 Big E(07장)
- 상품 도식: 03장 연도 슬라이더의 뒷면 도식을 `JeanBack`으로 분리해 공유. 같은 연도는 어디서나 같은 디테일로 그려진다. 사진(generated 이미지)은 쓰지 않기로 결정
- 사이즈 추천기: 세탁 후 원하는 허리·기장 → 수축률로 태그 사이즈 산출, 태그 기장과 세탁 후 기장을 막대로 비교, 고르면 사이즈 버튼에 반영
- 장바구니: 우측 드로어(`<dialog>`), 수량·빼기·합계, localStorage 저장, 결제 버튼은 비활성 + 콘셉트 고지
- 연결: 챕터 끝 "이 시대의 한 벌", Inside Out 결과의 복각 추천(구간 안에 없으면 "가장 가까운 복각"), 표지 하단 밴드, 목차·푸터 링크
